# Cloud files

Working documents from the cloud agent sessions that built Quire 0.1.0 (2026-10-16 and 17),
copied from the agent's scratchpad so they survive the container. They are records, not
sources of truth: the specs, change folders and run reports win where they differ.

| Folder | What |
| --- | --- |
| `prompts/` | Packet prompts sent to worker agents: `P01`, `P07`, `P08` (MVP), `0002-*` (workspace UX), `0003-*` (production hardening). `*.full.md` are the resent versions with the coordinator addendum folded in |
| `addenda/` | Coordinator notes added to prompts between waves |
| `commit-messages/` | Drafted commit messages, attribution lines removed |
| `notes/` | 0003 P11 decisions, UX gate reports, a LinkedIn draft |

Left out on purpose:

- logs, databases, CPU profiles and screenshots;
- the cloned Joplin (AGPL), Obsidian API and SilverBullet sources. The study notes live in
  `references/`.
