# Obsidian: feature inventory

Snapshot of Obsidian as documented in obsidian-help at `08ef563f` (app around 1.14) and obsidian-api `9abd9605` (package 1.14.4). Source paths are relative to `upstream/obsidian-help/`. The **Default** column is the state in a new vault: `on`, `off`, or `n.a.` (always available, not a toggle, or not applicable). Values the docs do not state are from observed app behaviour and are marked "(unverified)".

ID scheme: `OBS-F-###`, grouped in blocks of ten per area. IDs are stable; never renumber, only append.
