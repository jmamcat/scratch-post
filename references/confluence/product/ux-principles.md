# Confluence (Cloud): UX principles

Principles inferred from documented Confluence Cloud behaviour (see features.md for sources). Each has a takeaway for Quire, a lean Markdown app.

| ID | Principle | How Confluence expresses it | Takeaway for Quire |
| --- | --- | --- | --- |
| CNF-UX-01 | The tree is the map | Every space has a content tree sidebar; pages can be parents; folders add structure with no content; hover + creates a child in place (CNF-F-044 to CNF-F-046). | Folder hierarchy is the primary navigation; allow a note to also be a folder (folder note) and create children from the tree. |
| CNF-UX-02 | Two save modes, made explicit | Pages have drafts, unpublished changes and a publish step with a version comment; live docs autosave with no publish (CNF-F-062, CNF-F-063, CNF-F-070). | Default to autosave; offer "publish" only where a team wants a reviewed state, and show which mode a note is in. |
| CNF-UX-03 | History is append-only | Restoring copies an old version as the newest; later versions stay; whiteboards and databases restore as a new item rather than overwrite (CNF-F-060, CNF-F-067). | Restore and conflict resolution always create a new revision; never discard the losing side silently. |
| CNF-UX-04 | Compare what you choose, hide what did not change | Two checkboxes then "Compare selected versions"; large unchanged sections collapsed (CNF-F-059). | Diff UI: pick any two revisions (or mine versus theirs), collapse unchanged runs, expand on demand. |
| CNF-UX-05 | Review pending changes before they go out | Badge for unpublished changes, "View changes" diff, "Revert to previous version" with a warning that it is unrecoverable (CNF-F-063). | Show "local changes not yet synced" with a diff and a clearly labelled discard action. |
| CNF-UX-06 | Conflicts are resolved by a person, with three plain choices | Offline sync auto-merges what it can, highlights same-region conflicts, and offers keep offline, keep online, or combine manually (CNF-F-114). | Merge-conflict review: auto-merge non-overlapping hunks; per conflict offer Keep mine, Keep theirs, Edit combined; apply as one new revision. |
| CNF-UX-07 | Discussion lives beside the content, not in it | Inline comments anchor to highlighted text; resolve removes the highlight; resolved threads stay findable and reopenable (CNF-F-071, CNF-F-073). | Store comments in a sidecar with text anchors; never write comment markers into the Markdown body. |
| CNF-UX-08 | One keyboard-first insert path | `/` or + inserts anything; Markdown shortcuts autoformat as you type (CNF-F-002, CNF-F-003). | One slash menu over a small widget set; Markdown typed literally is always valid input. |
| CNF-UX-09 | Semantic blocks over free styling | Panels come as five named types with preset color and emoji; decisions and action items are their own blocks (CNF-F-009, CNF-F-010, CNF-F-013). | Offer named callout types, not color pickers; semantics survive as plain Markdown. |
| CNF-UX-10 | Structure starts from a template | Space and global templates, blueprints with sample content, a gallery at creation time, variables (CNF-F-081 to CNF-F-085). | A `templates/` folder and a picker on "new note" cover most of the value. |
| CNF-UX-11 | Reuse by reference, edit at the source | Synced blocks and excerpts show content from one source; destinations are view-only and update when the source changes (CNF-F-028, CNF-F-029). | Use Obsidian embeds for reuse; embedded content is read-only in place with a "go to source" action. |
| CNF-UX-12 | Show who is here | Active editors shown as colored avatars, departed ones in greyscale (CNF-F-069). | Light presence (who has this note open or recently edited) reduces conflicts before they happen. |
| CNF-UX-13 | Open by default, restrict by exception | Content is open within a space; page restrictions narrow view or edit; roles replace the permission grid (CNF-F-096, CNF-F-098). | Start with space-level read/write only; add per-note restriction later if needed. |
| CNF-UX-14 | Links become previews | Pasted URLs unfurl into inline, card or embed views, configurable per domain (CNF-F-025). | Keep the URL in Markdown; render previews at view time; never rewrite the link text. |
| CNF-UX-15 | AI drafts are previewed before they land | Create with Rovo shows a preview to refine before "Add to Confluence"; Atlassian advises reviewing AI output (CNF-F-126). | Any generated or merged text goes through a review step before it becomes a revision. |
