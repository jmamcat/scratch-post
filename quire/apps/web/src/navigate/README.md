# navigate (web)

Getting around: file tree, quick switcher, command palette and its commands, search pane,
and the right pane (backlinks, outgoing links, outline, properties, local graph), plus the
global graph view (`graph/`).

- Public API: the components and `commands`.
- Depends on: `sync/`, `vault/`, `shared/`, `@quire/navigate`, `@quire/views` (graph data).
- Specs: `R-NAV-*`.
