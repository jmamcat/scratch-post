# review (web)

Collision review: the always-visible badge, the inbox drawer with per-hunk cards, Review
suggested items, and the banner on a note with an open conflict.

- Public API: `ConflictBadge`, `ReviewDrawer`, `NoteBanner`, `useConflicts`.
- Depends on: `sync/`, `shared/`, `@quire/merge`.
- Specs: `R-RVW-*`.
