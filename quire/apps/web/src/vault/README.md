# vault (web)

Working with one note: the CodeMirror editor, the inline title (rename), version history
with restore, and note path helpers (daily note, untitled names).

- Public API: `Editor`, `InlineTitle`, `HistoryDrawer`, path helpers.
- Depends on: `sync/`, `render/`, `shared/`.
- Specs: `R-VLT-06`, `R-NAV-07`.
