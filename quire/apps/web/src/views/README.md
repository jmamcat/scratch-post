# views (web)

Other ways to see the same vault in the sidebar: Recent, Domains, Tags, Timeline and Board.
Views never move files; grouping comes from `@quire/views`, display from `shared/GroupList`.

- Public API: `RecentView`, `DomainsView`, `TagsView`, `TimelineView`, `BoardView`.
- Depends on: `@quire/views`, `@quire/vault`, `sync/`, `shared/`.
- Specs: `R-VIEW-*`.
