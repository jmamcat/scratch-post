# @quire/render

Obsidian Flavored Markdown: one markdown-it parser with Obsidian's extensions, used both to
render the reading view and to extract links, tags and headings.

- Public API: `renderMarkdown`, `extractLinks`, `extractTags`, `extractHeadings`.
- Depends on: `@quire/vault`, markdown-it and plugins. Pure.
- Specs: `R-RND-*`; pinned by `scenarios/approved/render/`.
