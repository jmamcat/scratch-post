# Welcome to Quire

Quire keeps your notes as plain Markdown files and syncs them between a cloud server, a
local node at home and your phone, even when one of them is offline.

> [!tip] Try this first
> Press **Ctrl/Cmd+O** and type `alpha` to jump to [[Projects/Alpha|Project Alpha]].

## What you can write

- [[Formatting]] shows the syntax: callouts, tasks, highlights, footnotes.
- [[Projects/Alpha]] links back here, so this note has a backlink.
- Today's daily note: run **Open today's daily note** from the command palette (Ctrl/Cmd+P).

## Sync, in one picture

> [!info]- How collisions are handled
> Edits to different parts of a note merge silently. Two edits to the same sentence are
> merged word by word and flagged for a glance. Anything that cannot merge safely waits in
> the **Review** inbox, with both versions kept.
